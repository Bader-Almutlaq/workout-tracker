# T-053: Warm-ups only when asked; small add-on plates on cables

- **Milestone:** R9 (warm-ups) · **Depends on:** none (no schema change) · **Model tier:** mid (Codex Terra)

## Goal

The owner's decisions (`docs/design/PROPOSALS.md` → *Owner decisions*):

1. **Warm-ups are not generated by default.** The owner adds them when wanted.
2. **Cables (and other machines the owner chooses) take small add-on plates,** so their loadable steps are finer than the 5 kg stack.

The warm-up colours and row layout wait for the owner's Strong screenshots: keep today's styling.

## Specification

1. **Off by default.**
   - `warmupSetCount` NULL now means **no automatic warm-ups**.
   - A per-exercise value of 1–4 (set in the exercise's Loading fields) turns automatic generation on for that exercise, exactly as today.
   - 0 stays "none".
   - Rename the field's options so this is clear: "Warm-up sets: Off (default) / 1 / 2 / 3 / 4".
2. **Add warm-ups on request.**
   - Each exercise card's menu gets **Add warm-up sets**.
   - It inserts the planned warm-ups before the working sets, using today's heuristic count (keep it as `suggestedWarmupCount`) and the first working weight (typed, or the previous workout's).
   - They appear as greyed suggestions that ticking accepts, refresh while untouched, and follow all existing protection rules.
   - If there is no working weight yet, the item is disabled with the hint "Enter a working weight first."
   - If warm-ups already exist, the item reads **Remove suggested warm-ups** and removes only untouched, uncompleted suggestions.
3. **Existing data:**
   - Workouts already logged keep their warm-ups.
   - A workout in progress keeps any warm-ups already generated.
   - Nothing is migrated.
4. **Cable steps.**
   - Cable profile: step **1.25 kg** (lb: 2.5), minimum 2.5 kg (lb: 5). Most stacks are 5 kg, and an add-on plate gives the in-between loads.
   - Selectorised **machine** stays at 5 kg (lb: 10).
   - The per-exercise load-step override still wins for both.
   - Update the `LoadingDefaults` doc comment (Heuristic: add-on plates) and the hand-computed tests (e.g. cable 23 kg → down 22.5, nearest 22.5; 23.2 → nearest 23.75).
